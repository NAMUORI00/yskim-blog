# 수익화 가이드 (AdSense + 제휴)

기술 블로그 독자(개발자)는 광고 차단 사용률이 높아 **애드센스 단독 수익은 작습니다**.
애드센스는 "기본값"으로 켜 두고, 실질 수익은 **제휴(affiliate)** 와 이후
**디지털 상품·뉴스레터·협찬**으로 확장하는 단계 전략을 권장합니다.

---

## 1. Google AdSense

### 승인 요건 체크리스트

- [ ] 커스텀 도메인 연결 (`blog.namuori.net`) — `*.pages.dev`는 승인 불리
- [ ] HTTPS (Cloudflare 기본 제공)
- [ ] 오리지널 양질 글 **15편 이상** (각 800자+ 권장)
- [ ] 법적 페이지: 소개 / 개인정보처리방침 / 연락처 / 면책조항 — **완료됨**
- [ ] 모바일 친화 · 명확한 내비게이션 — 현재 테마 충족
- [ ] 도메인 연결 후 최소 수 주 운영(신규 도메인은 반려율 ↑)

### 연결 방법

1. <https://adsense.google.com> 가입 → 사이트 `blog.namuori.net` 추가.
2. 발급된 게시자 ID(`ca-pub-XXXXXXXXXXXXXXXX`)를 `src/config.ts`에 입력:

   ```ts
   export const SITE = {
     // ...
     adsensePublisherId: "ca-pub-XXXXXXXXXXXXXXXX",
   };
   ```

   → ID를 넣으면 `<head>`에 AdSense 로더가 자동 삽입됩니다(비우면 광고 OFF).
3. **ads.txt**: AdSense 대시보드의 안내대로 처리합니다. 두 방법 중 하나:
   - AdSense의 "사이트 ads.txt 자동 관리" 사용(권장), 또는
   - 저장소에 `static/ads.txt` 파일을 만들고 아래 한 줄 작성:

     ```text
     google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0
     ```

4. 광고 노출 방식:
   - **자동 광고(권장)**: 위 게시자 ID만 넣으면 AdSense 자동 광고가 동작합니다.
     글 본문은 Notion에서 작성하므로 자동 광고가 가장 실용적입니다.
   - **고정 슬롯**: 특정 위치에 광고를 고정하려면 레이아웃(`.astro`)에서
     `AdSlot` 컴포넌트를 사용합니다(예: 글 본문 아래).

     ```astro
     ---
     import AdSlot from "../components/AdSlot.astro";
     ---
     <AdSlot slot="1234567890" />
     ```

   (`slot`은 AdSense에서 만든 광고 단위 ID)

## 2. 제휴 마케팅 (기술 블로그에 더 효과적)

### 쿠팡 파트너스

1. <https://partners.coupang.com> 가입·승인.
2. 장비·도서·도구 리뷰 글에 제휴 링크 삽입.
3. **고지 의무**: Notion 글에 **`affiliate`(또는 `제휴`) 태그**를 추가하면 글 상단에
   제휴 고지가 **자동으로 노출**됩니다. Notion에서 태그만 달면 되므로 별도 편집이
   필요 없습니다(`src/components/AffiliateDisclosure.astro`, 문구는 거기서 수정 가능).
   - 사이트 전역 고지는 이미 `면책조항` 페이지에 포함되어 있습니다.

### 글로벌 제휴 (개발자 친화)

- 개발 도구/호스팅/온라인 강의 추천 링크는 클릭·구독당 단가가 높습니다.
- 실제 사용한 도구만 추천해 신뢰(E-E-A-T)를 지키세요.

## 3. 다음 단계 (트래픽·권위 누적 후)

- 디지털 상품(유료 노트·템플릿·전자책)
- 뉴스레터(구독자 확보 → 협찬/소개)
- 기술 협찬·컨설팅·강의 유입 퍼널

개발자 블로그는 광고보다 **"전문성 → 기회 연결"** 에서 수익 규모가 큽니다.

## 4. 주의

- 광고는 본문 가독성을 해치지 않는 선에서 1~2개로 시작하세요.
- 제휴·광고가 있는 글은 반드시 고지하세요(법적 의무이자 신뢰 요소).
- 애드센스 정책 위반(클릭 유도, 콘텐츠 부족 페이지 광고 등)은 계정 정지 사유입니다.
